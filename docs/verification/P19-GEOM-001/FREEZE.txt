HAZARDS CARRIED INTO THE RUN
----------------------------
H1  ONE TRANSIENT LINK FAILURE was seen before the harness work began. While the
    1.5 GB debug test executable was relinked interactively alongside other work,
    ld exited 1; the diagnostic was LOST because the command's own output filter
    dropped every line without "error:" or "FAILED" in it. Two subsequent links
    of the SAME objects, with nothing else running, succeeded. The harness links
    after its compiles finish, so it does not reproduce the conditions. If a
    build stage fails at the link, that stage is re-run FROM CLEAN and the result
    is not accepted from a retry inside the same run.

H2  A COMPILE-FAIL CONTROL TARGET IS NOT A TEST. The cfdgeom control did not
    compile under -Werror=unused-function, and `ctest -R compile_fail.cfdgeom.`
    reported 29 of 29 passing over a project that did not build — because the
    control is a build target that ctest never builds. Fixed before the freeze,
    and the all-targets build now completes clean on all three presets. Nothing
    in the repository TESTS that a control builds, so the next group making the
    same mistake is caught only by a full build. Recorded as a recommendation,
    not fixed here: it is a change to the shared compile-fail harness.

H3  EIGHT REFERENCE-MESH TESTS NOW DEPEND ON P16 EMITTING GAP-FREE ELEMENT
    HANDLES. `MeshBuilder` has no explicit-handle overload for an element, so the
    rigid-transform sweep rebuilds a mesh and REQUIREs that the handles come back
    identical. A future backend that leaves gaps fails that REQUIRE loudly rather
    than silently comparing different faces, which is the intended shape, but the
    dependency is not documented anywhere else.


WHAT THIS MILESTONE IS
----------------------
The finite-volume geometric metrics of a topology derived from a proved mesh
(ADR-065): the cell volume and centroid, the face area vector, area, unit normal
and centroid, the owner-to-neighbour and cell-to-face vectors, the orthogonal
distance, the orthogonality cosine, the non-orthogonality angle, the skewness,
the boundary outward normal, the per-cell surface-vector sum and its closure, and
a measured summary that judges nothing.

TWO REVIEWS RAN BEFORE THIS FREEZE and both found real defects, including a hard
gate failure and a claim in the ADR and the public header that had been written
without the work behind it. Four of the builder's guards turned out to be
REACHABLE where the ADR had called them unreachable. The details are in ADR-065,
Decision 5 and in the evidence README; the freeze is taken after all of it.
