COUNTING TRAPS
--------------

P19-GRAD-001's freeze recorded nine and its evidence added a tenth; attempt 1's
freeze added (a) to (h). All still apply. These are the ones that fired AFTER
attempt 1's launch, every one in the author's own measurement rather than in the
result.

(i) A PARSE THAT FINDS NOTHING READS AS A PASS. The first attempt to count
    attempt 1's stage table anchored its regex at end-of-line, and every stage
    line ends with a TIMESTAMP after the exit code. It matched 0 of 17 lines and
    reported "stages that did NOT exit 0: 0" -- literally true and completely
    empty. This is P19-DOF-001's own failure in a new place: a check whose
    denominator is zero cannot fail. The parse prints the number of stage lines
    it found FIRST now, and 17 is itself the assertion.

(j) `grep -c "Failed"` RETURNS 158 HITS PER PASSING LOG. Every one is a test
    NAME -- 73 on Start lines, 79 on passing result lines, and 6 more on Start
    lines whose names contain the word `error`. A repeat log gives 410. They are
    classified individually now, not waved away. (And `grep -c "Passed"`
    overcounts by exactly 1 per full log and 5 per repeat log, for the same
    reason: a test name ends `...WhetherOrNotItPassed`.)

(k) COUNTING BY DISPLAY NAME UNDERCOUNTS BY 2. Two names are each registered
    under two ctest IDs, so 6446 IDs showed as 6444 names. Counts are taken by
    ctest ID.

(l) A COUNT TRUE OF EIGHT BODIES IS NOT TRUE OF ONE. A review fix asserted
    `internalFaces > 1000` on the Cylinder, which has 946, by analogy with the
    closure case's `totalInternal > 1000` -- a sum over ALL EIGHT reference
    bodies. That is this milestone's own trap (`internalFaces() > 100` on the
    Block, which has six) and P19-GRAD-001's before it (`> 10` on the same
    body), for the THIRD time in two milestones.

(m) AN ANCHOR VALIDATOR EARNS ITS KEEP. The review-fix patch script checked all
    ten anchors before writing anything and refused the whole run when one
    matched twice -- `if (view.path == Path::MassFlux) {` appears in two places.
    Nothing was written and the script named the anchor. That is trap (a) from
    attempt 1's freeze, answered.

(n) `grep -c $'\\r'` IN GIT BASH MATCHES EVERY LINE. It reported 817 lines with
    a carriage return in a file that has none; the byte count from Python is
    CR 0, LF 817. A line-ending check has to count bytes.
