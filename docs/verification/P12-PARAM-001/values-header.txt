Measured values of the P12-PARAM-001 tests (Release build of the qualified tree).
Produced by: build/release/bin/bettercad_tests.exe "[p12]" -s --reporter xml --rng-seed 1, filtered by
values.py (kept in this directory): every passed CHECK_THAT and every passed CHECK whose expansion shows
values, with the test case, section and INFO/CAPTURE context. Each entry: file:line, the assertion, then
Catch2's expansion (values printed exactly). REQUIRE lines, repeats of an identical entry within a test case
and expansions over 1000 characters (whole-file text) are left out. bits(x) is the IEEE-754 bit pattern of x,
so `bits(a) == bits(b)` compares two doubles exactly.
